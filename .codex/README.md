این پوشه مرجع پایدار برای ادامهٔ طراحی و توسعهٔ فرانت‌اند فروشگاه React Store است.

## در شروع هر جلسه

1. ابتدا `git status`، شاخه و HEAD فعلی را بخوان؛ وضعیت پروژه ممکن است نسبت به commit مبنا تغییر کرده باشد.
2. `PROJECT_CONTEXT.md` را برای شناخت واقعی کد و کامپوننت‌ها مطالعه کن.
3. `FRONTEND_AUDIT.md` را برای ایرادهای شناخته‌شده و سطح اطمینان بخوان.
4. `NEXT_STEPS.md` را برای اولویت‌ها و کارهای پیشنهادی مرور کن.
5. `WORKING_AGREEMENTS.md` را برای قواعد همکاری و طراحی رعایت کن.

## هدف این مستندات

جلوگیری از تحلیل دوبارهٔ پروژه در هر گفت‌وگو و جدا کردن **آنچه در کد دیده شده** از **اصلاحات پیشنهادی**.

## نکتهٔ مهم

این بررسی از طریق مشاهدهٔ کدهای موجود در GitHub انجام شده است؛ در این مرحله هیچ `npm install`، `npm start`، build، تست خودکار، بررسی تصویری مرورگر یا تست واقعی API اجرا نشده است. هیچ‌یک را PASS فرض نکن. کد اپلیکیشن برای ایجاد این پوشه تغییر نکرده است.
